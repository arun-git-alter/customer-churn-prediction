THE PROJECT

Make retention more
proactive.

Customer churn can quietly erode recurring revenue and weaken long-term relationships. This project explores how a machine learning model can estimate churn likelihood from a customer's tenure, service mix, contract, and billing profile.

The output gives teams a consistent starting point for review. It does not explain why a person will leave or replace customer research.

HOW A PREDICTION WORKS

Four steps. One consistent response.

The interface sends the same feature names and types expected by the Flask endpoint.

  1. 01

    Complete the form

    Browser validation checks required selections and numeric ranges.

  2. 02

    Submit customer data

    The page sends a JSON POST request to /predict.

  3. 03

    Validate and score

    Flask checks categories and numbers, then asks the saved model for a churn probability.

  4. 04

    Review the result

    The page displays the API’s probability, churn label, and risk category.
